𝒇x v0.0.17
Fast, native coding agent for the terminal.

fx starts an interactive session by default. Use `fx ask` to run one
noninteractive request.

Usage:
  fx [flags]
  fx [flags] "<prompt>"
  fx <command> [...flags] [...args]

Commands:
  ask <prompt>                           Run one noninteractive request

  pr [context]                           Draft or publish a pull request
  issue [context]                        Draft or publish a GitHub issue

  sessions                               List saved sessions for the current
                                         workspace
  session <last|id>                      Inspect, resume, or recover saved
                                         sessions
  session resume [last|id]               Resume the latest workspace session or
                                         a session by id
  session recover <id>                   Copy a recoverable corrupt session

  login [vercel|codex|grok] [--api-key]  Sign in to a model provider
  logout [vercel|codex|grok]             Sign out of a model provider
  provider <name>                        Choose the active model provider
  models                                 List available models

  teams                                  Choose a Vercel AI Gateway team
  credits|balance                        Show Vercel AI Gateway credits

  usage [--period <today|7d|month>]      Show your provider's usage and spend

  status                                 Show configuration and runtime
                                         information
  doctor                                 Check that fx can work here, with a fix
                                         for each problem
  mcp <command> ...                      Manage MCP servers without opening the
                                         interactive shell
  slack <install|status|refresh>         Install and manage the workspace Slack
                                         bot locally
  permissions                            Show the permission mode and rules
  workspace                              Manage additional workspace directories
  config                                 Show and change fx settings
  upgrade|update                         Upgrade fx on the selected release
                                         channel
  acp                                    Start an ACP server over stdio
  completion <shell>                     Print a shell completion script
  help                                   Show this help

Flags:
  --context-limit <spec>                   Set name=bytes|off; repeatable
  --add-dir <path>                         Add a workspace directory; repeatable
  --no-additional-dirs                     Ignore saved additional directories
  --tool-placement <spec>                  Move a built-in tool: tool=toolbox or
                                           tool=direct; repeatable
  --provider <name>                        Override the model provider for an
                                           interactive session (gateway, codex,
                                           grok, or a configured name)
  --provider-order <a,b,...>               Prefer these gateway providers in
                                           order for an interactive session
  --provider-strict, --no-provider-strict  Restrict an interactive session to
                                           the providers in --provider-order, or
                                           clear the restriction
  --model <id>                             Override the model for an interactive
                                           session
  --effort <level>                         Override the reasoning effort for an
                                           interactive session
  --profile <name>                         Run an interactive session in an
                                           agent profile from ~/.fx/agents or
                                           the repository's .fx/agents
  --instances <n>                          Start n fx instances in one
                                           interactive session, each with its
                                           own conversation; Down on an empty
                                           composer, Ctrl+X, or /agents lists
                                           them to switch
  --fast, --no-fast                        Turn Fast mode on or off for an
                                           interactive session
  --ultrafast, --no-ultrafast              Request Ultrafast mode on or off for
                                           an interactive session
  --permission-mode <mode>                 Set the permission mode for an
                                           interactive session: ask, auto, or
                                           full-access
  --ask, --auto, --full-access             Shortcuts for each permission mode;
                                           --yolo means --full-access
  -c, --continue                           Resume the remembered workspace
                                           session
  -r, --resume [last|<id>]                 Pick a saved session, or resume the
                                           latest or an exact ID
  -h, --help                               Display this help and exit
  -v, --version                            Print the fx version and exit

Examples:
  fx
      Start a fresh interactive session

  fx "Fix the failing login test"
      Start a session with a first prompt

  fx ask "Explain the changes in this repository"
      Run one request and exit

  fx session resume last
      Continue the latest session for this workspace

  fx status --json
      Inspect the current configuration as JSON

Run `fx <command> --help` for command-specific usage and options.
Run `/help` inside an interactive session for slash commands.

Learn more about fx:  https://fx.sh/docs
Report a problem:     run `/feedback` inside fx
